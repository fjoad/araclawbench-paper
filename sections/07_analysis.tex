\paragraph{The localized file system.}
The most common desktop failure in Arabic is a path. The agent knows the task
wants a file in \texttt{Documents}, types that literal path into a save
dialog, and is told the folder does not exist, because on the Arabic desktop
the folder is called \ar{المستندات}. A person would look at the sidebar; the
agent tends to retype the path, and often keeps retyping it until the budget
ends (Figure~\ref{fig:overview}). \todo{Count; note that the same instruction
names the path in Latin script in both arms, so this is an environment effect
rather than a translation effect.}
